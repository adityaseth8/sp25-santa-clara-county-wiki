=====Data Retention Policy=====

=== Overview ===
A set of rules which determines how long data should be stored and readily available before it is archived or deleted. Applies to the 8th and final step of the data lifecycle management. County employees set custom rules with the Microsoft Azure Blob Storage Lifecycle Management tool to automatically archive or delete data based on the number of days since the data was created, last modified, or last accessed. Archiving infrequently accessed data limits the likelihood that an attacker can quickly retrieve it. Deleting obsolete data saves the County money.
